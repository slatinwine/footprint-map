# 足迹地图

Apple / iOS 设计风格的地图标注工具：GPS 定位当前位置，在地图上收藏标注点，并通过链接一键分享，无需服务器与账号。

## ✨ 功能特性

- 定位：基于浏览器 Geolocation 持续获取 GPS / 网络位置，显示精度圈与蓝色定位点
- 标注：点击「✚ 标记此处」收藏当前位置，或地图右键 / 长按任意位置添加；每个标注可命名、写备注、单独分享或删除
- 四种底图切换：高德（默认）/ 浅色 / 深色 / OpenStreetMap；高德底图自动做 WGS-84 ⇄ GCJ-02 纠偏，海外瓦片加载失败时自动切回高德
- 分享：标注数据编码进链接 hash（Base64），对方打开即见橙色图钉，无需请求服务器；优先调用系统 Web Share
- 数据：标注自动存 localStorage；支持导出 / 导入 JSON 备份，可一键清空
- 自动适配深色模式与手机安全区

## 🚀 使用方法

无需构建。直接用浏览器打开 `index.html` 即可，地图瓦片需联网加载。

> 注意：浏览器定位仅在 `https://` 或 `localhost` 环境下可用，本地直接双击打开（file://）时定位功能会受限。

## 🛠️ 技术栈

- Leaflet 1.9.4（CDN 引入）+ 原生 JavaScript
- Web API：Geolocation、Web Share API、`localStorage`、URL hash

## 📁 目录结构

- `index.html` — 全部界面、地图逻辑与数据存取
